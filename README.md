# ML Gif Pro

Gerador profissional de GIF animado físico a partir de imagens da Media Library (WordPress 6.0+, PHP 8.1+, Imagick).

- **Slug / pasta / arquivo principal:** `ml-gif-pro/ml-gif-pro.php` (imutáveis). Neste repositório o plugin fica na raiz; o workflow empacota em `ml-gif-pro/`.
- **Código-fonte:** este repositório (será privado). **Atualizações:** releases públicas em [`ml-gif-pro-releases`](https://github.com/mlopesdesign/ml-gif-pro-releases), asset `ml-gif-pro-vX.Y.Z.W.zip`.
- **Release:** push de tag `vX.Y.Z.W` → `.github/workflows/release.yml` valida, empacota (respeitando `.distignore`) e publica aqui e, com o secret `GH_RELEASE_TOKEN`, também no `-releases`.
